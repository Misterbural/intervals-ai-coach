# Initial Intake

Principle: the intake sets the direction of the season. Exact weekly time slots and target volume are not locked here—they are decided at each block brief (`coach-block-brief`).

1. Read `athlete-profile.md`, `endurance-methodology.md`, `coaching-journal.md`, and the active sport module(s) (`cycling.md`, `running.md`, `trail.md`, `triathlon.md`) present in the Project Library.
2. Analyze the last 3 months on intervals.icu: weekly volume and load by sport, current CTL/ATL/TSB, time-in-zone distribution, recent best efforts, and available wellness metrics (HRV, RHR, sleep). Summarize in 5 lines. If older activities are empty shells from Strava, note it and use a backup connector if available. If returning from injury or layoff, explicitly note that older benchmarks do not represent current fitness.
3. Ask all necessary questions in short rounds (3–5 questions per message) across as many turns as needed; do not draft the file until no major gaps remain. Cover:
   - season goals (or explicit lack of target race), dates, sport/format, and success criteria; process goals;
   - health, injury history, or return-to-training status: medical/physio clearance, restrictions, sensitive areas;
   - known season constraints: on-call weeks, travel, busy work periods;
   - preferences: indoor vs outdoor, favorite/disliked sessions, group/club sessions or virtual racing;
   - strength equipment available (gym vs home); daily nutrition habits and cooking preferences.
4. If no race is set, never invent one: propose a general endurance development period with no fixed race date.
5. Draft a complete `season-goals.md` (Goals, Starting Point, Known Season Constraints, Preferences, Season Plan, Target Event Demands). Present it for review; once approved, save it to the Project Library (or output the full file to upload). Update `athlete-profile.md` the same way if medical clearance or missing details were added.
6. If medical/physio clearance is still pending, state it clearly and pause—never build a block beforehand. Otherwise, offer to launch `coach-block-brief` for Block 1.
